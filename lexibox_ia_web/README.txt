LEXIBOX IA — SITIO WEB DE 5 PÁGINAS
===================================

ARCHIVOS
--------
index.html       Página de inicio con slider, presentación del equipo emprendedor, beneficios y tarjetas digitales.
producto.html    Presentación del producto, funcionamiento y categorías.
juegos.html      Juego de 10 preguntas, puntaje y cuadro de honor.
equipo.html      Presentación de los cinco integrantes, misión y visión.
contacto.html    Formulario de contacto listo para conectar con Formspree.
css/styles.css   Todos los estilos visuales, responsive y organizados por grupos.
js/main.js       Menú móvil, slider y chatbot de respuestas predefinidas.
js/games.js      Tarjetas vinculadas a juegos, preguntas, puntaje y cuadro de honor.

CÓMO ABRIR
----------
1. Descarga y descomprime LexiBox_IA_Web.zip.
2. Abre la carpeta.
3. Haz doble clic en index.html.
4. Navega por las cinco páginas desde el menú.
5. En Inicio o Producto puedes explorar las tarjetas; pulsa “Practicar esta palabra” para jugar con esa palabra. También puedes entrar a Juegos y elegir una tarjeta o el reto mixto. No se utilizan códigos QR.

FORMULARIO FORMSPREE
--------------------
En contacto.html busca:
action="https://formspree.io/f/TU_ID_DE_FORMSPREE"

Reemplaza TU_ID_DE_FORMSPREE por el identificador real que te entrega Formspree.
Ejemplo de formato (no uses este texto como ID real):
action="https://formspree.io/f/xxxxxxxx"

CHATBOT
-------
El chatbot incluido es funcional con respuestas predefinidas (no es una IA conectada).
Para conectarlo a un modelo de IA real se necesita un backend seguro. No coloques claves
secretas de APIs directamente en archivos JavaScript públicos.

PUNTAJES Y CUADRO DE HONOR
--------------------------
El juego registra el nombre, el puntaje y muestra los diez mejores resultados.
Los datos se guardan en localStorage del navegador y solo se ven en ese mismo dispositivo
y navegador. Para compartir un ranking entre distintos celulares o computadoras se requiere
una base de datos y un servicio backend.
